  • The markup never says **. Inside <tree-node> every path is one level deep — label, value, total, children. ** is an authoring symbol for the state definition only, and never reaches a bound path.
  • The Σ on a row is nodes.**.total, read through the mount. The node four levels down reads nodes.*.children.*.children.*.children.*.total; that accessor is grown the first time something reads it, so only the depths you actually visit exist.
  • + child appends a node at that level. The subtree becomes deeper than anything the page had rendered before, and every Σ above it — plus Total and Height — follows with no extra wiring.
  • Clear selection is $setAll("nodes.**.selected", [], false): one broadcast to every depth. The [] is mandatory — leaving the indexes out is refused, because the write API takes no context to bind a depth to, wherever it is called from.
  • Total is $getAll("nodes.**.value", []).reduce(…), the merged reading of all depths (depth-first, pre-order, ascending index). It agrees with the sum of the top-level Σ values because the recursive getter counts each level exactly once.
  • Height shows that aggregation is not only addition: get "nodes.**.depth"() is the same shape with max, and each row prints its own subtree height as hn.
  • The input contract is a tree. Reaching the same array instance from two parents is refused (wcs/recursion-shared-list, wcs/recursion-cycle) rather than silently double-counted.
