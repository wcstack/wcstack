## 2. B14③ ボリュームの注入口

**現状。** コンポーネントはホスト側で `state.taxRate: user.taxRate` と書けば、ホストのパスを自分の名前で読める（部分マウント）。ボリュームにはこれが無い。ボリュームのパスは単純な接頭辞の連結で解決している。

- `webComponent/volumeShared.ts` の `createVolumeChroot` が `receiver[mountPath + "." + prop]` を返す。`$getAll` / `$setAll` / `$resolve` / `$postUpdate` も同じ規則。
- コンポーネント側には、最長一致で引くエントリ表がある（`webComponent/mount.ts` の `IMountRecord`）。その表は B14① の `readonly` と B14② の `mappedKeys` を持ち、書き込みは `translateInnerWritePath` を通る。

**案。** コンポーネントの部分マウントと同じ語彙を、ボリューム要素に書けるようにする。

```html
<wcs-state mount="cart" src="./cart.js" data-wcs="state.taxRate: settings.taxRate"></wcs-state>
```

`cart.js` の中では `this.taxRate` がルートの `settings.taxRate` を読む。今、`<wcs-state>` 要素の `data-wcs` にある `state.*` は、存在しない `state` プロパティへの入れ子の書き込みになるだけなので、意味を与えても互換は壊れない。

要件（§3.4）は「いずれも書き込み翻訳の単一点に載る」としている。そのため、ボリュームも `IMountRecord` の表に載せ、接頭辞の連結をやめて `translateInnerPath` / `translateInnerWritePath` を通す形を推す。

## 3. B5 明示のプロパティ形

**現状。** 名前が `on` で始まればイベント束縛になる（`parseBindTextsForElement.ts`）。そのため `online: x` は `"line"` イベントを待ち、`only: x` は `"ly"` を待つ。明示のプロパティ構文は無い。`prop.x` は「`element.prop.x` への入れ子の書き込み」という意味で既に使われている。左辺の先頭ドット（`.online:`）は、今は空の第 1 セグメントになり、適用時に壊れるだけである。

**案。** 左辺の先頭ドットを「必ずプロパティ」の形にする。lit-html の `.prop=${…}` と同じ読み方になる。

```html
<my-status data-wcs=".online: isOnline; onclick: refresh"></my-status>
```

右辺の `.name` は行相対のパスで、左辺の `.name` とは位置で区別できる。展開の重複除去キー・SSR の属性表・双方向の判定は第 1 セグメントを見ているので、正規化して `online` を渡す。

## 4. B12 と #2

**B12。** 候補は監査 §5（`dependOn` / `untracked`、`afterRender`、`add` / `sub`、`padStart` / `padEnd` …）にあるが、名前は書き手が毎日触る面なので、1 つずつ決める。

- 仕組みは次の 2 つを推す。
  - フィルタは `core/filterRegistry` の別表でエイリアスを持つ。今、`filterMeta` のキーとフィルタ表のキーは一致するようテストで固定されているので、その関係は崩さない。
  - 宣言キーは、state を設定するときに 1 回だけ正規化する。両方の綴りを宣言したらエラーにする。
- 告知は、lint の info（正式名の提案）を最初から出す。ランタイムの警告は 3.x の最後の minor だけにする（2.6 の `wcs/v3-migration` と同じ運用）。

**#2。** [state-named-wildcard-index-design.md](./state-named-wildcard-index-design.md) §4.1 は、パス文字列にオフセットを入れる案を退けている。パス文字列はシステム全体の鍵で、1 回のパースで（段, オフセット）が決まらなければならないからである。さらに今、`items.+1.name` は**絶対 index 1** として読まれる（`Number("+1")`）。`+N` は空いた綴りではない。

- API／スコープ形（同文書 §9）を推す。
- 行の葉への書き込みが隣の行へ届く台帳が要る（同 §7-1 の落とし穴を含む）。
- 同じパスの中の連鎖を、行の順に評価する必要がある。

別に設計と試作を行い、計測してから出す。
