wcstack: tilt ball maze (signals edition)

The same game as examples/state-tilt-maze, same four I/O nodes — but the reactive core is @wcstack/signals: hot-loop values are plain variables, and only what the DOM shows is a signal.

  • Sensors need a secure context: localhost works; on a phone use HTTPS (or adb reverse).
  • iOS grants tilt via the Start button's tap (gesture-gated permission, absorbed by <wcs-tilt>).
  • Shake detection uses <wcs-accelerometer> (Chromium/Android); elsewhere the Retry button covers it.
  • Desktop: drag the board, use the arrow keys (focus the board first — it is in the Tab order), or emulate orientation in DevTools > Sensors.
  • Start waits only while the sensor packages load. Block esm.run/@wcstack/tilt in DevTools > Network to watch it degrade: the import() rejects, Start unlocks anyway and the HUD reports drag-only control.
