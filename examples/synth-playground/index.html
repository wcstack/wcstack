wcs-synth playground — a synthesizer made of HTML tags

Nesting is the signal chain (signal flows downward); anything nesting can't express is routed by id (out="bus", param="frequency"). Play with the on-screen keys, your computer keyboard (A–; = notes, WET… = sharps, Z/X = octave), or a MIDI keyboard. View source: the page is the patch.

Poly synth — 8 voices, 3 osc → filter (LFO) → env → bus → delay

Mono bass — legato + glide, keys only (computer keyboard stays on the poly synth)

Toy experiment — see README for the tag reference. Audio starts on your first click / key press (browser autoplay policy).
